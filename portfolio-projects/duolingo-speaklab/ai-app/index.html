How the AI works

When deployed with an API key, SpeakLab sends your typed practice answer to a secure server endpoint, which requests structured feedback from an AI language model. Keys never appear in the browser.

We do not store your practice text in this application. The AI provider processes requests under its own policies.

The previous rule-based offline demo is still available if the AI service is unavailable.

SpeakLab is an independent educational prototype and is not affiliated with Duolingo. This is typed language practice, not speech recognition, a formal language assessment or a validated learning outcome. Read product decisions and safeguards.
