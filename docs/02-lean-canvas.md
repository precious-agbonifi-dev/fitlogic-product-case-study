# Lean Canvas — FitLogic (hypotheses)

| Block | Proposed answer |
| --- | --- |
| Problem | Inconsistent exercise, too many disconnected resources, little visible progress |
| Existing alternatives | Notes apps, generic workout videos, fitness tracking apps, one-to-one coaching |
| Customer segments | Busy beginners and returning gym-goers; secondary segment: independent trainers |
| Early adopters | Professionals restarting fitness with 2–3 available sessions per week |
| Unique value proposition | **A realistic workout plan that adapts to your week and makes consistency visible.** |
| Solution | Goal-led onboarding, weekly programme, completion tracker, progress summary |
| Channels | Trainer referrals, short-form educational content, fitness communities, search |
| Revenue | Possible freemium tier and premium personalised plans — unvalidated |
| Costs | Engineering, cloud hosting, support, content, acquisition, privacy compliance |
| Key metrics | Onboarding completion, first-workout activation, weekly adherence, week-4 retention |
| Unfair advantage | Founder’s practical coaching insight; not defensible until demonstrated |

## Biggest unknowns
1. Is adherence the most important unmet problem?
2. Does adaptive scheduling improve consistency?
3. Is a paid offering meaningfully better than free alternatives?
4. Which segment values the experience most?

## Test before investing
Start with interviews, a clickable prototype and a concierge pilot. Change the canvas when evidence contradicts assumptions.
